## 发现与处置

1. Canal parser 的失效位点未必作为 TCP 异常上报：补充共享只读 meta.dat、SHOW BINARY LOGS 范围及 server_uuid 同源检查；元文件读取竞争只重试，不回退初始 P。
2. 对账可能越过积压 DDL/TRUNCATE：补充候选源位点屏障、期间变更 ID 失效与控制事件阻塞；不能以空批表示已追平。
3. 1.1.8 空事务节流影响屏障活性：固定 Spring 配置放行空事务，保留无法证明时延后、5分钟告警及人工维护兜底；安排真实测试。
4. 索引不存在时 ES 可能隐式创建：关闭 Repository 自动创建，并将 ES 自动创建策略只对 idx_question 禁止；维护显式创建，其他索引不受影响。
5. 自动空库修复可能绕过人工清表：自动模式不清空已有索引，显式受控 repair 完整核对后可清理多余项。
